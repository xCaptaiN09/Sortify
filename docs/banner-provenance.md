# Sortify banner

Asset: `banner.png`, used by README.md and module.prop. It replaces the original
dark banner. Generated on 2026-11-15 with the built-in imagegen tool, using the
current WebUI screenshot `build/design-home-1280.png` as the style reference.
The reference is a browser capture of this repository's UI, with labeled demo data.

Output: 2098 × 749 PNG. The generated image was copied into the project and
losslessly recompressed with ImageMagick. Pixel signatures before and after
recompression match. No cropping, resizing or pixel edits were applied.

# Sortify WebUI direction — 2026-11-15

Cap's latest instruction replaces the earlier light/dark appearance request.
One light theme, no outlined cards, minimal premium composition with artwork,
fine rules, color fields and gradients. The two supplied BOLT/Twinkle references
are visual references; they are not product screens or factual copy to reproduce.

## Thesis

Make a capable Android download organizer feel like a clear editorial utility.
The four existing pages and every sorting control remain usable and truthful.

## Own world

Cool paper, near-black ink, Bodoni Moda display type and DM Sans controls.
The top gradient fades into the page rather than enclosing a hero card. The
authored globe/file illustration, flush colored result counts and thin dividers
translate the reference's visual language into a working tool. No rounded cards,
boxed fieldsets, fake file statistics or automatic dark-mode switching.

## Story

Home leads to immediate sorting or a non-destructive preview. Scheduling stays
separate from manual sorting. Preview explains file outcomes; History provides
Undo and protection; Settings exposes the agreed configuration and advanced rules.

## First viewport

Recognizable Sortify wordmark, four text navigation links, the fading gradient,
a large two-line serif heading and file line art. On narrow screens the art sits
above the heading without covering it. The primary actions lead the routine
section, before schedule details. Sample data is always labeled as demo data.

## Form and motion

The user supplied and repeatedly confirmed the references and concrete direction.
Implementation follows that pinned brief directly; no concept roll, seed or app
comp was generated or approved. Do not interpret this document as a roll record.

Open sections and thin rules; rectangular black primary actions; flat mint,
lavender, peach and blue result cells. Inputs use one bottom rule. The only
authored entrance is the short artwork reveal, disabled with reduced motion.

## Quality bar

No framed dashboard panels or crowded decoration. Readable labels at 320px,
no horizontal overflow through 1920px, keyboard-visible focus, offline fonts,
explicit unsupported environment state and working direct-file demo. Existing
sorting, preview, Undo and settings behavior must remain intact. Android device
and real manager validation are separate from host/browser verification.
